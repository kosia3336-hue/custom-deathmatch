# 포카드 스킨 에셋

| 파일                                    | 용도                  | 처리                                                                           |
| --------------------------------------- | --------------------- | ------------------------------------------------------------------------------ |
| `/skins/four-card/felt-background.webp` | 게임 셸 배경          | 생성 베이스를 WebP로 최적화                                                    |
| `/skins/four-card/card-back.webp`       | 비공개 카드 뒷면      | 생성 베이스를 3:4로 중앙 크롭 후 WebP 최적화                                   |
| `/skins/four-card/joker-moon.png`       | 흰색 0 카드 중앙 조커 | 사용자가 제공한 그림카드에서 글자·외곽선을 제외하고 일러스트만 투명 PNG로 추출 |

숫자, 문양, 카드 흰 바탕, 선택·비활성 상태는 `FourCardCard.tsx`와 `.skin-four-card-*` CSS가 담당한다. 래스터에 텍스트를 넣지 않아 작은 가상 플레이어 카드에서도 표시가 선명하게 유지된다.
