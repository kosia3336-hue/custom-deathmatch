# 드림샵 · 베팅 가위바위보 효과음

직접 제작한 짧고 둥근 신스 벨/플럭. 외부 샘플이나 보이스는 사용하지 않는다.
브라우저에서는 WAV만 재생한다. 공통 SFX 음량·음소거를 따른다.

| 파일 | 용도 | 느낌 |
| --- | --- | --- |
| win.wav | 승 선택 / 승부 결과 승 공개 | 올라가는 뚱·띵 |
| draw.wav | 무 선택 / 승부 결과 무 공개 | 같은 높이로 톡·톡 |
| lose.wav | 패 선택 / 승부 결과 패 공개 | 내려오는 뚱·땅 |
| success.wav | 베팅 성공 공개 | 5음 상승 반짝임 |
| fail.wav | 베팅 실패 공개 | 부드러운 3음 하강 |
| refund.wav | 베팅 반환 공개 | 올라갔다 돌아오는 음 |

로컬에서 각 WAV 파일을 직접 열면 재생할 수 있다. 공개 사운드 페이지는 추가하지 않는다.
재생 길이/경로/음량은 manifest.json. 재생 매핑은 lib/audio/skins/dreamshop.ts.
재생성: `python3 scripts/audio/build-dreamshop.py` (Python 표준 라이브러리만 필요).
44.1kHz, mono, PCM 16-bit, 피크 0.62, 시작/끝 페이드로 클릭 제거.
